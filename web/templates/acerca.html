StockPredict IA · piloto local

Acerca de StockPredict IA

Proyecto académico de predicción de ventas con datos reales de Corporación Favorita.

Objetivo del proyecto

Estimar ventas diarias con redes neuronales

Usar ventas históricas y contexto temporal/comercial para estimar ventas del día siguiente por tienda y familia. Las recomendaciones de reposición pertenecen a una etapa futura.

Paso diario
Tienda · familia
MLP / PyTorch

Alcance implementado

Lectura y validación, historia causal, one-hot, escalado, entrenamiento, reanudación, evaluación y consultas locales.

Sin stock actual, pedidos sugeridos ni intervalos de confianza.

Proceso de extremo a extremo

01 / Datos

Historia causal

train.csv, siete días previos observados. Los huecos no son ventas cero.

02 / Entrenamiento

MLP baseline

Adam y MSE. Escalador y categorías ajustados solo con entrenamiento.

03 / Evaluación

MAE y RMSE

Test cronológico reservado y comparación con ventas de hace siete días.

04 / Consulta

Predicción real

Flask reutiliza Python y el checkpoint existente. Sin entrenamiento web.

Tecnologías y límites

Python y PyTorch

Modelo MLP, pandas para datos y scikit-learn para transformaciones.

HTML Stitch + Flask

Interfaz adaptada del diseño exportado. API exclusivamente local con validación de entradas.

Colab y Drive

Notebook preparado para entrenamiento y recuperación. Estado remoto no verificado por esta aplicación.

El piloto usa tiendas 1 y 2 y familias AUTOMOTIVE, BABY CARE y BEAUTY. No integra todavía petróleo, feriados ni transacciones externas. No se atribuyen investigadores, licencias o publicaciones no documentados.
