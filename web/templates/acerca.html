StockPredict IA · prototipo académico

Acerca del proyecto

Predicción de ventas futuras por producto individual con Python, PyTorch y Flask.

Datos y modelo

Un flujo de datos sintéticos

El catálogo contiene 30 productos de cinco categorías y tres tiendas. Las ventas sintéticas abarcan desde 2023-01-01 hasta 2026-11-16. Las predicciones posteriores usan producto, tienda y calendario; no dependen de ventas reales recientes.

Pronóstico futuro
MLP / PyTorch

Arquitectura

Controlador Flask → servicio de aplicación → repositorio de productos y adaptador del modelo.

El inventario es sintético; no se generan compras ni movimientos de existencias.

Alcance y limitaciones

Inferencia

Usa un checkpoint sintético local. La web no entrena ni sobrescribe modelos.

Variables

No se suministran precio ni promoción; la predicción no está condicionada por esos valores.

Limitación

Las ventas y existencias no son reales ni demuestran precisión comercial.
