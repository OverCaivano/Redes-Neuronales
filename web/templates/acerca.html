StockPredict IA · modelos locales · Favorita

Acerca de StockPredict IA

Proyecto académico de predicción de ventas con datos reales de Corporación Favorita.

Objetivo del proyecto

Estimar ventas diarias con redes neuronales

Usar ventas históricas y contexto temporal/comercial para estimar ventas del día siguiente por tienda y familia. Las recomendaciones de reposición pertenecen a una etapa futura.

Paso diario
Tienda · familia
MLP / PyTorch

Alcance implementado

Dos checkpoints locales, consultas históricas con ambos modelos, pronóstico recursivo de siete días con el completo y backtest limitado de validación.

Sin stock actual, pedidos sugeridos ni intervalos de confianza.

Proceso de extremo a extremo

01 / Datos

Historia causal

train.csv, siete días previos observados. Los huecos no son ventas cero.

02 / Entrenamiento

MLP piloto y completo

13 y 95 entradas. Transformaciones ajustadas solo con los datos de entrenamiento.

03 / Evaluación

MAE y RMSE

Evaluación diaria del piloto y backtest recursivo del completo sobre una muestra de validación.

04 / Consulta

Predicción y pronóstico

Flask reutiliza checkpoints locales. Sin entrenamiento desde la web.

Tecnologías y límites

Python y PyTorch

Modelo MLP, pandas para datos y scikit-learn para transformaciones.

HTML Stitch + Flask

Interfaz adaptada del diseño exportado. API exclusivamente local con validación de entradas.

Artefactos locales

La aplicación usa los checkpoints y datos del repositorio. No requiere acceso a Drive para las consultas.

El piloto se limita a tiendas 1 y 2 y tres familias. La interfaz muestra sus nombres en español y conserva los identificadores originales para las consultas; el completo usa las categorías de su checkpoint. No incorpora stock actual, pedidos, precios ni feriados. Las recomendaciones de reposición no están implementadas.
